The section below allows you to customise your selected display. 

Overview

Customising your walks display involves using a simple template using placeholders and conditional logic. It allows you to customise the display of the walk/event display.

Basic Syntax

Simple Placeholders

Use curly braces with field names to insert values:

Hello {name}!
When rendered, where 'name' = 'John', this outputs: Hello John!

Conditional Blocks (if)

Show content only when a field has a value:

{if:company}Works at {company}{/if}
  • If company is provided: Works at Acme Corp
  • If company is empty/missing: (nothing)

Conditional Blocks (if_not)

Show content only when a field is empty or missing:

{if_not:email}No email provided{/if_not}

Shorthand Syntax

There's a convenient shorthand for common patterns:

Hello {from ?company}

This automatically expands to: Hello {if:company}from {company}{/if}

The ? before the field name means "only show the preceding text if this field exists".
