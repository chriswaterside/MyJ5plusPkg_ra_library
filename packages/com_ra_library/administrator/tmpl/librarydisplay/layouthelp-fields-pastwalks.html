Available fields

  • title - the walk's title, plain text
  • title_link - the title, wrapped in a link to that walk's own single-item page
  • url - the link to that walk's single-item page on its own (e.g. for a custom "View" button)
  • category - the walk's category title, or blank if uncategorised
  • description - the walk's description (HTML, as entered)
  • national_grade - e.g. "Easy access", "Moderate"
  • distance_miles - e.g. "5.2 miles"
  • distance_km - e.g. "8.4 km"
  • walk_date - e.g. "2 Aug 2026"
  • walk_date_dow - e.g. "Sunday 2 Aug 2026"
  • walk_leader - the walk leader's name

Photo/file fields

These render as complete, ready-made blocks of HTML - you can place the whole block wherever you like in your layout and style it with CSS, but you can't rearrange what's inside the block field by field.

  • featured_image - an <img> of the featured photo (or the first photo if none is marked featured), blank if there are no photos
  • image_grid - a thumbnail grid of every photo, each linking to its full-size copy, blank if there are no photos
  • gpx_list - a list of GPX file download links, blank if none
  • gpx_map - the featured (or only) GPX file's route, embedded inline as a map, blank if none
  • gpx_map_list - a list of the OTHER GPX files (not the one gpx_map is already showing), each a link that opens the route on a map in a popup, blank if none
  • document_list - a list of titled document download links, blank if none

Custom fields

Fields you define under Components > Ra_library > Past Walk Fields. They are only available when at least one field has been created.

  • custom_fields - every custom field that has a value, as a ready-made list (label and value). A field set to "Do not automatically display" is left out of this block
  • field:name - the value of one custom field, where name is the field's Name (shown in the Fields list - lowercase letters, digits and hyphens), e.g. {field:terrain}. Blank if the record has no value. Works in conditions too: {if:field:terrain}Terrain: {field:terrain}{/if} or {Terrain: ?field:terrain}
