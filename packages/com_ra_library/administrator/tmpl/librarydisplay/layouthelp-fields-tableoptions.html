Add one or more of the keywords below, separated by spaces, in the Options column for each row. This works the same way whether the table's data comes from the SQL option, the JSON feed option, or a CSV file with "Where are the column options for this CSV file?" set to "Set below".

Putting rows on the map

  • latitude - together with a column marked longitude, these two columns are used as the row's position on the map. Both the List tab and the Map tab are shown.
  • longitude - see latitude above.
  • gridref - marks this column as an OS Grid Reference to use as the row's position instead of latitude/longitude. Also shows the Map tab. Note this can be slower, as the software has to calculate the latitude and longitude from the grid reference.

If none of latitude/longitude or gridref is used on any column, the data is not shown on a map - only the List tab is displayed.

Display

  • table - the column is displayed in the List tab.
  • popup - the column is displayed in the marker pop-up shown when you click a marker on the map.
  • sort - adds a sort option for the column, if it is displayed in the table.
  • filter - adds a filter option for the column, if it is displayed in the table.
  • linkmarker - adds a link in the table row that shows the marker on the map when clicked.
  • link - the column's values are URLs; they are displayed as hyperlinks rather than plain text.

Data type (used for correct sorting)

  • int or integer - the column only contains whole numbers, so the sort option sorts numerically rather than alphabetically.
  • real or float - the column only contains decimal numbers, so the sort option sorts numerically.
  • date - the column is a date in the format DD/MM/YYYY, so the sort option sorts by date rather than as text.

Alignment in the List view

  • left - the column is left aligned.
  • right - the column is right aligned.
  • centre or center - the column is centre aligned.

Example

table sort filter left

shows the column in the List tab, sortable, filterable, and left-aligned.
