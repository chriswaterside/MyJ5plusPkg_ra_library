Available fields

These are for the Category Tree display's "Customise Category/Branch layout" field only - the fields shown while browsing down through subcategories, before a leaf category (one with no subcategories of its own) is reached and its actual items are shown instead (see the Customise List layout field's own Fields button for those tokens).

  • title - the category's title, plain text
  • title_link - the title, wrapped in a link to browse into that category
  • url - the browse-into link on its own
  • description - the category's own description field, as entered in Categories (HTML, as entered)
  • item_count - number of items directly in this category (not counting its subcategories)
  • total_item_count - total items anywhere in this branch (this category plus every subcategory, however many levels deep)
  • featured_image - a representative photo: the featured (or first) photo belonging to the first item anywhere in the branch that has one, empty if none
